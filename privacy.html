プライバシーポリシー

Sift（以下「Sift」）は、個人の開発者が作った個人用のメールアプリです。このページでは、Sift が扱うデータ、とくに Google アカウントから受け取るデータの扱いを説明します。

1. Google から受け取るデータ

  • Gmail のメールとフォルダ（ラベル）。権限 https://mail.google.com/ を使い、IMAP で受信・整理し、SMTP で送信します。
  • Gmail のアドレスと差出人名（Gmail API の users.getProfile と users.settings.sendAs.list）。アカウントの設定に使います。
  • ログインの情報（アクセス トークンとリフレッシュ トークン）。

2. データの使い方

受け取ったデータは、あなたが使うメールの機能のためだけに使います。メールの表示・検索、迷惑メールやメールマガジンの振り分け、返信が必要なメールのお知らせ、あなたが操作した既読・フラグ・移動・削除の Gmail への反映、あなたが書いたメールの送信です。振り分けは、あなたの端末の中で行います。広告には使いません。

3. 保存

メールのコピーは、あなたの端末の中にある Sift のデータベースに保存します。ログインの情報は暗号化して保存します。開発者のサーバーはなく、開発者がデータを受け取ることはありません。利用状況の送信（アクセス解析）もしません。

4. 第三者への提供

Sift は、Google から受け取ったデータを第三者に渡しません。ただし、次の機能をあなたがオンにした場合に限り、それぞれの相手にデータが送られます（どれも最初はオフです）。

  • AI（Claude）：メールの差出人・件名・本文（最大 6,000 文字）を Anthropic 社の Claude に送り、振り分けと要約に使います。あなた自身の Anthropic の API キー、またはあなた自身の Claude Code のログインを使います。
  • スマホのブラウザへの通知：通知の内容（差出人と件名）を、ブラウザの通知サービス（Apple・Google・Mozilla）を経由して送ります。内容は暗号化されていて、通知サービスは読めません。
  • ntfy による通知：通知の内容（差出人と件名）を、あなたが設定した ntfy のサーバーに送ります。
  • ほかの端末からの利用：同じネットワークにあるあなたの端末（スマホなど）を Sift とつなぐと、その端末にメールを表示します。

Google から受け取ったデータを、汎用の AI・機械学習モデルの開発・改善・学習に使うことはありません。

Sift による Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

5. 削除

Sift からアカウントを削除すると、その端末に保存したメールのコピーとログインの情報も削除します（Gmail のサーバーのメールは消えません）。Sift へのアクセスは、いつでも Google アカウントの「サードパーティ製のアプリとサービス」から取り消せます。

6. 変更とお問い合わせ

このポリシーを変えるときは、このページを更新します。お問い合わせは GitHub Issues へどうぞ。

Privacy Policy

Sift is a personal email app made by an individual developer. This page explains what data Sift handles, in particular the data it receives from Google accounts.

1. Data Sift receives from Google

  • Your Gmail messages and folders (labels), using the scope https://mail.google.com/: mail is received and organized over IMAP and sent over SMTP.
  • Your Gmail address and sender name (Gmail API users.getProfile and users.settings.sendAs.list), to set up the account.
  • Sign-in tokens (access and refresh tokens).

2. How Sift uses the data

Only for the email features you use: showing and searching your mail; sorting out spam and newsletters; pointing out mail that needs a reply; applying what you do (read, flag, move, delete) to your Gmail; and sending the mail you write. Sorting runs on your device. The data is not used for advertising.

3. Storage

Copies of your mail are stored in Sift’s database on your own device. Sign-in tokens are stored encrypted. There is no developer server, and the developer never receives your data. Sift sends no analytics.

4. Sharing

Sift does not share data received from Google with third parties, except when you turn on one of these optional features (all are off by default):

  • AI (Claude): the sender, subject and body (up to 6,000 characters) of a mail are sent to Anthropic’s Claude to sort and summarize it, using your own Anthropic API key or your own Claude Code sign-in.
  • Notifications to a phone’s browser: the notification (sender and subject) is delivered through the browser’s push service (Apple, Google or Mozilla), end-to-end encrypted so the push service cannot read it.
  • ntfy notifications: the notification (sender and subject) is sent to the ntfy server you set up.
  • Your other devices: when you connect your own device (such as a phone) on the same network to Sift, your mail is shown on that device.

Google user data is not used to develop, improve or train generalized AI or machine-learning models.

Sift’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. Deletion

Removing an account from Sift deletes the copies of its mail and its sign-in tokens from that device (mail on the Gmail server is not touched). You can revoke Sift’s access at any time at your Google Account’s third-party apps page.

6. Changes and contact

Changes to this policy will be posted on this page. Contact: GitHub Issues.
